# Music Player

Designed a front-end, responsive, dynamic, interactive and user-friendly music player application where users can play, pause, mute songs in home and favourite modules and also add songs to our favourite list to list our favourite songs and also admin can add and delete songs. 

Tools used: HTML, CSS, JavaScript, Bootstrap.
